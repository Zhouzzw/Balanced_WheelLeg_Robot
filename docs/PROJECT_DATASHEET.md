# RM WheelLeg 串联腿轮腿底盘 · 运控固件数据手册

> 本数据手册为项目权威参考底座，数据均溯源至仓库真实源码（`Chassis.c/.h`、`RoboControl.c`、`Communicate.h`）。配置值取源码实值，注释/历史取值以 `[待补充]` 标注。

---

## 1. 项目概述

**串联腿构型平衡轮腿机器人**的底盘运动控制固件：遥控/键鼠输入 Vx/Vy/Wz 与腿长/腿摆角目标，经**哈工程正运动学 → 变参数 LQR → VMC 虚拟模型控制 → 雅可比力分解**的 1ms 闭环完成运动解算，并内建**跳跃、自动上台阶、翻倒自起、离地检测**等特殊机动。交付形态为 STM32G474 + FreeRTOS 内嵌固件（Keil MDK-ARM 工程）。

## 2. 核心配置规格

### 2.1 平台与实时配置

| 配置项 | 数值 | 设计动机 |
|--------|------|---------|
| 主控 | STM32G474VETx (Cortex-M4F, 170MHz) | 带 FPU + DSP（CMSIS-DSP `arm_math.h` 加速正运动学三角）；单芯片内嵌全功能底盘 |
| 实时系统 | FreeRTOS V10.3.1 (CMSIS RTOS v1) | `Robo_Task`(Realtime) 状态调度 + `Chassis_Task`(High) 运控 |
| 运控周期 | 1ms（`Chassis_dt = DWT_GetDeltaT`，`osDelay(1)`） | 轮-腿共生高动态系统需亚 ms 级闭环致隐稳定 |
| 腿长范围 | 0.15 ~ 0.35 m（`Limit_float(Leg_Length, 0.38, 0.15)`） | 机械伸缩短建立高重心主动悬挂；0.14/0.38 为氮气弹簧压缩/伸展极限 |

### 2.2 控制结构配置

| 配置项 | 数值 | 设计动机 |
|--------|------|---------|
| 主控制器 | 变参数 LQR，10 状态反馈 | 状态反馈兼顾多维度精确性；增益随腿长三次多项式插值适应全工作点 |
| 虚拟力控制 | VMC：腿力 `F_L/F_R` + 关节力矩 `Tj` → 力雅可比 `Jt_l/Jt_r` → 4 关节力矩 `TP[4]` | 力端物理直观，雅可比统一映射避免直接关节级计算 |
| LQR 加权 Q / R（激活） | `Q=diag([20000 1500 250 100 100000 1000])`、`R=diag([120 4])` | 高权重于机体位移(20000)与俯仰(100000)——保稳优先于机动 |
| LQR 加权 Q / R（备选，注释） | A: 稳定飞坡 `[16000 1000 250 100 70000 1000]/[120 4]`；B: 联盟赛综合 `[4000 1500 600 5000 100000 500]/[150 8]` | 同体系多套整定，按场景切换（调参留档） |
| 增益拟合 | 12 个增益 × 三次多项式 `K=a·len³+b·len²+c·len+d`（`Poly_Coefficient[12][4]`） | 离线 MATLAB 多点拟合腿长非线性的实时近似 |
| 状态量构成 | θ_L, θ̇_L, θL̈, xb, ẋb, φ, φ̇, θ_R, θ̇_R, θ̈R（theta 角加速度差分估计） | 轮腿双端 + 机体俯仰全维反馈 |

### 2.3 电机与执行器配置

| 配置项 | 数值 | 设计动机 |
|--------|------|---------|
| 关节电机 ×4 | DAMIAO 8009，MIT 控制（FDCAN1） | 串联腿髋关节需大扭矩行程；MIT 报文直接下发力矩 |
| 轮电机 ×2 | DJI M3508（FDCAN2），250Hz 力矩 | 转速高、惯量匹配；`Torque2Current` 标定 |
| 关节力矩限幅 | `Torque_Joint` 限 ±80 | 保铰链/电机安全 |
| 车轮力矩限幅 | `TP[4]` 轮端限 ±6.0 | 防轮疯转功率超限 |

### 2.4 特殊机动阈值配置

| 配置项 | 数值 | 设计动机 |
|--------|------|---------|
| 氮气弹簧补偿 | `spring_table_T[-1]+` `Get =` 段插值，`safety_force_limit=200N` | 中 0.14→90~100N 至 0.38→159~180N 非线性回复力作动态前馈；200N 防力异常 |
| 离地支持力阈值 | `Detect_Force = 50N` | 轮端动力学估算值低支持力判离地；`Fn<50N` 且 `MotionAccel_n_Z < -5` 双重确认 |
| 重力补偿 | `Gravity_Comp = 90N` | 腿端静态重力前馈，减轻 LQR/PID 负担 |
| 软着陆力 | `Soft_landing_Comp_F = 120N` | 离地后腿长恒力输出，空中随姿态平稳落地 |
| 上台阶磕碰阈值 | 摆角 `>14°` 且 角速度 `>1.7` | 双腿同时满足才判磕到台阶，防误触发 |
| 跳跃档位 | `Jump_Level` 1/2/3 → 蹬伸腿长 0.20/0.25/0.33m | 遥控/键鼠三档选择跳跃强度 |

### 2.5 滤波与观测器配置

| 配置项 | 数值 | 设计动机 |
|--------|------|---------|
| 车速观测器 | 2 维卡尔曼（左右各一），编码器速度=测量、IMU 加速度=输入 | 融合抑制轮滑/编码器跳变 |
| 卡尔曼 F 矩阵 | `{1, 0.002, 0, 1}`（注释标注"控制周期 0.002s"） | ⚠ 与运控 1ms 周期存疑，见第 10 章已知限制 |
| Z 轴加速度滤波 | 3 点中值 + 一阶低通（`K_Lowpass_fliter = 0.05`）双级 | 中值去毛刺 + 低通去波动，供离地检测可信输入 |

## 3. 核心算法与流程配置

### 3.1 运控主链路（Chassis_Task，1ms）

1. `Get_Control_Data()` — 取目标/反馈：位移、车速、pitch、关节总角，装配 `state_lqr[6]`
2. `Calculated_displacement()` — 编码器总角 → 车轮位移 / 速度
3. `xvEstimateKF_Update()` — 轮速 + IMU 加速度融合出滤波车速 `V_ave`
4. `calculateValues_Q_l/r()` — 关节总角 → 虚拟腿长/摆角 + 力雅可比 `Jt`（哈工程 5 连杆正运动学）
5. `State_Filter()` — Z 轴加速度中值 + 低通
6. `add_six_state()` — 装配 10 状态 `x`
7. `calucateK()` + `calucateLQR_L/R()` — 变参数 LQR → 轮力矩 + 关节摆角力矩
8. `Jump_Control() / Off_ground_Detection() / Up_Step_*() / Recover_from_Ground()` — 特殊机动叠加力/力矩
9. `calucateTp()` — 雅可比分解 → 4 关节力矩 `TP[4]`
10. `Output_Current()` — 关节力矩×`K_gear2chain` + 轮电流 → CAN 下发

### 3.2 跳跃状态机（梯形阶）

| 态 | 动作 | 关键参数 |
|----|------|---------|
| 0 | 降腿蓄力 | `Leg_Length=0.15`，双腿 <0.16m 累计 30tick 转移 |
| 1 | 斜坡蹬腿起跳 | `F = Spring_comp + K_slope·330N`，`K_slope += 25·dt` 缓加力 |
| 2 | 空中收腿 | 收腿 PID、关节只留摆角 LQR×0.25、轮置 0，稳定 40tick 转移 |
| 3 | 落回复位 | `Leg_Length=0.20`，清标志 |

### 3.3 上台阶状态机

| 态 | 动作 | 关键参数 |
|----|------|---------|
| 检测 | 伸最高腿 0.35 + 解除腿长限速 `V_limit=2.3` | 磕碰判定:摆角 >14° 且 角速度 >1.7 |
| 0 | 后摆腿 ±55° + 收腿至 <0.18m，轮置 0 | 双腿到位 25tick 转移 |
| 2 | 恢复常规 | 复位 `UpStep_Flag/Dect_Flag` |

### 3.4 翻倒自起 / 缓起立

| 阶段 | 动作 | 关键参数 |
|------|------|---------|
| 判定 | pitch 正负判前栽(前栽=1)/后仰(=2) | —
| 态0 | 平齐双腿前摆，轮置 0 | 摆角速度环归中，找水平位形 |
| 态2 | 收腿至最短 0.15 | `Fold_*_Leg_Speed_PID`，腿 <0.17m 累计 200tick |
| 态3 | 恢复 `Chassis_STATIC` + `Allow_to_Stand=1` | 清标志 |
| 缓起立 | 倒地后先缓慢收腿 | 腿 <0.17m 累计 100tick → `Allow_to_Stand=1` |

### 3.5 运行模式差异

| 模式 | 差异点 | 原因 |
|------|--------|------|
| OFF / 失能 | 关节 MIT 下发 0、轮电流 0、清全部功能标志 | 安全兜底，防重使能关节点跳 |
| 常规运控 | 变参数 LQR 全维 + 所有机动可用 | 需求 |
| 上台阶态 | 解除 V 限速（`V_limit=2.3` 不随腿长递减） | 高腿短距加速磕台阶需放开限速 |
| 离地/空中 | 轮置 0、腿长切软着陆恒力 120N、关节只保摆角 LQR | 避免空中轮乱转干扰姿态 |

## 4. 质量保障策略（无环境迁移维度）

单板内嵌固件，无仿真→实机域差（真机即目标环境）。质量保障来自：

- **安全限幅层**：关节力矩 ±80、车轮力矩 ±6、功率反解限幅、腿长限速——多重硬限兜底，防发散/超限（属于"信任边界防错误"，刻意从严）。
- **误动作防护**：离地检测双重条件 + 跳跃/上台阶/起立等机动间互相屏蔽（`Jump/UpStep` 期间不执行离地检测）、`Simple_TipOver` 预警可主动降腿增稳。
- **状态安全**：`Robo_Stop()` 统一清零功能标志防疯车；缓起立 `Allow_to_Stand_Flag` 门控上电起立。

> 注：项目无自动化测试 / CI 记录，固件以台上联调 + 真机验证为主（`[待补充]` 具体验收记录）。

## 5. 部署/交付链路

```
遥控/键鼠(SBUS/RS485) → Robo_Task 解码(Vx/Vy/Wz, 状态, 功能标志)
    → Chassis_Task 运控 1ms (正运动学→LQR→VMC→特殊机动→calucateTp)
    → CAN 下发: 关节 DAMIAO 8009 (FDCAN1, MIT) + 轮 M3508 (FDCAN2, 250Hz)
    ← 编码器/IMU 反馈闭环
外部: 裁判系统(UART) 功率上限 + 超电(FDCAN1) → 功率反解限幅
交付形态: Keil 编译固件 .hex → J-Link/DAP-Link 烧录 → 真机运行
```

链路上传端（遥控→目标）无频率标注数据缺失；运控内部链路 1ms 周期。部署为固件烧录交付，无独立部署脚本（`[待补充]` 烧录 SOP 记录）。

## 7. 项目亮点

1. **氮气弹簧非线性动态补偿** —— 做法：以腿长-力映射表分段线性插值，将弹簧非线性回复力作动态前馈注入腿长力控。对比基准：无补偿时腿长 PID 被弹簧非线性干扰、难收敛。带来的价值：腿长力控等效为纯惯性对象，是跳跃/上台阶/起立等所有腿长动作平稳执行的前提（量化增益待实测，`[待补充]`）。
2. **变参数 LQR 增益随腿长三次多项式插值** —— 做法：12 增益离线拟合腿长。对比基准：固定增益无法兼顾 0.15~0.35m 全工作点。价值：单参数插值在 1ms 内实时逼近多工作点最优增益，免去在线重解黎卡提方程。（对上台阶/跳跃中大幅变腿长场景的稳定性增益待实测）。
3. **离地支持力动力学估算 + 双重判据** —— 做法：不解力传感器，由 `M·g + 腿端轴向力` 估算轮端支持力，双腿同时离地 + Z 轴负加速度双确认。对比基准：单纯加速度阈值法易误判/漏判。价值：省传感器成本的可靠离地检测，为空中姿态与软着陆提供前提。
4. **多机动状态机共用单雅可比分解端** —— 做法：跳跃/上台阶/起立/离地仅改写 `F_L/F_R` 与 `Torque_Joint` 取值来源，复用同一 `calucateTp()`。对比基准：各机动各起一条控制环的常见做法。价值：控制结构单一、力矩合成一致、新增机动成本低。

## 8. 设计决策记录（关键）

1. **独立腿模型用变参数 LQR 而非传统双环 PID**
   - 问题：轮腿共生系统高动态、多状态强耦合，固定增益需兼顾全工作点。
   - 候选：多工作点增益表切换（瞬变不平滑）vs 三次多项式插值。
   - 选择：三次多项式插值 `K`（源码 `LQR_K_calc`）。理由：平滑过渡、离线拟合省运行资源。
   - 事后验证：上车可行（阶段注释含 3 组 Q/R 整定留档），量化验证 `[待补充]`。

2. **VMC 力端分解 + 雅可比映射，而非直接关节级力矩计算**
   - 问题：腿长力与关节摆角力矩物理耦合，直接算关节力矩繁琐易错。
   - 选择：上层产虚拟力/力矩，经 `Jt` 方阵映射到关节。理由：力端物理直观、映射统一。
   - 事后验证：代码链路完整（`calucateTp`），效果 `[待补充]`。

3. **离地检测用动力学估算支持力而非力传感器**
   - 问题：足端力传感器成本/空间/带宽限制。
   - 选择：`Fn = m·g + 腿端轴向力` 解析估算 + 双重判据。理由：零额外硬件、实时。
   - 验证：阈值 `Detect_Force=50` 有整定注释，误判率 `[待补充]`。

4. **氮气弹簧补偿用查表插值而非解析式**
   - 问题：弹簧力-腿长非线性无简洁解析。
   - 选择：标定映射表 + 分段线性插值 + 200N 限幅。理由：贴合实测、抗漂移、安全兜底。
   - 验证：控制链路就绪，`[待补充]` 标定精度。

## 9. 已修复的工程问题

| 现象 | 根因 | 修复 |
|------|------|------|
| 设完零点直接进入运控疯车 | 设零后状态未就绪 | `If_SettingZero` 设零后 `osDelay(100)` 延时再进运控（源码注释：延时100ms防止设完零点进入运动控制疯车） |
| 上电/倒地起立突跳 | 无缓起立门控 | `Smooth_Restand_Func` 缓收腿 + `Allow_to_Stand_Flag` 门控后才进常规运控 |
| 起步/刹车位移跳变 | 位移积分器残留脏数据 | 起步清积分、刹车锁目标位移死锁稳停（注释：「关键修复」） |
| 降腿时负向限幅误判离地 | 降腿瞬间 Z 加速度跨阈值 | 离地确认加 `MotionAccel_n_Z < -5` 判据（注释：防止与降腿时达到的负向输出限幅导致误判离地） |
| 轮疯转功率超限 | 轮速超限未控 | `Limit_Left/Right_Wheel_RPM_PID` 限速补偿 + 功率反解限速（注：当前软禁未启，`[待补充]` 是否恢复） |

## 10. 已知限制与后续方向

- **⚠ 卡尔曼 F 矩阵与控制周期存疑**：`xvEstimateKF` 的 `F = {1, 0.002, 0, 1}` 注释标注"控制周期 0.002s"，而运控 `Chassis_dt` 为 1ms。若以 0.002s 建模但 1ms 采样，KF 状态转移存在时间尺度失配——需核对/统一（**用户裁决**）。
- **`Simple_TipOver_Detection`（倾倒预警）未启用**：源码注释「功能待测试！！」，预警→主动降腿增稳逻辑完整但关闭。
- **轮速限速补偿 PID 当前软禁**：`Limit_Left/Right_Wheel_RPM_PID` 相关分支注释掉，轮疯转保护现依赖功率反解限幅。
- **离地检测依赖腿部速度环/力矩**，大规模外部扰动下支持力估算精度受限，误判率待实测。
- **真机动态量化缺失**：跳跃高度/滞空、上台阶成功率、到位精度等均无实测日志，是后续补测重点。

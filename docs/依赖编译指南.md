# 依赖编译指南（从零构建）

> 从零复现本项目，最卡人的不是固件代码本身，而是 **工具链 + Keil 软件包依赖**。本指南把
> 「换一台新电脑：装 Keil / CubeMX / 烧录器 → 装设备包与 CMSIS-DSP 包 → 编译 → 烧录 → 真机复现」
> 的完整链路写清楚。
>
> 本项目是 **STM32 内嵌固件**（非 ROS / Server 工程）：无包管理器、无脚本安装，所有源码随
> Git 仓库分发，第三方中间件已打入 `Drivers/`、`Middlewares/`。唯一**不随仓库分发**的依赖是
> Keil 软件包 `ARM.CMSIS-DSP`（`arm_math.h` —— 运控的 CMSIS-DSP 三角/矩阵加速源），必须单独装。

## 0. 总览：要装哪些东西

### 0.1 外部工具链（需自己安装）

| 依赖 | 角色 | 获取 | 必要性 |
|------|------|------|--------|
| **Keil MDK-ARM 5.x** | 编译 / 烧录 IDE | 官网安装 | 必须 |
| **STM32CubeMX** | `.ioc` 引脚配置再生成 | 官网安装 | 改引脚时 |
| **Keil.STM32G4xx_DFP** | STM32G4 设备支持包 | Keil Pack Installer | 必须 |
| **ARM.CMSIS-DSP** | `arm_math.h`（运控加速） | Keil Pack Installer | 必须 |
| **调试器 + 驱动** | J-Link / DAP-Link / ST-Link | 硬件 |

> ⚠ **`arm_math.h` 源码里被 `Chassis.c` 等引用，但仓库内查不到**——它来自 Keil 软件包
> `ARM.CMSIS-DSP`。复现时**第一步就装它**，否则编译报 `arm_math.h: No such file`。
> ⚠ Keil 工程已配置 **AC6（ARM Compiler 6）** 编译器（`.uvprojx` 含 `<uAC6>`），编译时保持默认，不要切到 AC5。

### 0.2 随仓库分发的依赖（无需另装）

| 依赖 | 位置 | 角色 | 许可证 |
|------|------|------|--------|
| FreeRTOS V10.3.1 | `Middlewares/Third_Party/FreeRTOS` | 实时内核（CMSIS RTOS v1 封装，`portable/RVDS/ARM_CM4F` 移植） | MIT |
| STM32G4xx HAL 驱动 | `Drivers/STM32G4xx_HAL_Driver` | 外设 HAL 库 | BSD-3-Clause |
| CMSIS 核心 + G4 设备 | `Drivers/CMSIS` | 启动/寄存器定义 | Apache-2.0 |
| ST USB Device 库 | `Middlewares/ST/STM32_USB_Device_Library` | USB CDC 虚拟串口 | BSD-3-Clause |

## 1. 通用前置（第一次复现必做）

```bash
# ① 安装 Keil MDK-ARM 5.x（需注册/许可）
# ② 安装 STM32CubeMX（修改 .ioc 时用）
# ③ 安装调试器驱动（J-Link / DAP-Link / ST-Link）
# ④ Keil 打开工程后，用 Pack Installer 装：
#     - Keil.STM32G4xx_DFP       （设备支持）
#     - ARM.CMSIS-DSP            （arm_math.h，必装！）
```

> 工程根含 `Kawashiro_Frame_G474.ioc`（CubeMX 源）与 `MDK-ARM/Kawashiro_Frame_G474.uvprojx`（Keil 工程）。

---

## 2. 编译与烧录

```bash
# ① 打开工程
#    MDK-ARM/Kawashiro_Frame_G474.uvprojx

# ② 确认软件包（Pack Installer）：Keil.STM32G4xx_DFP + ARM.CMSIS-DSP 已装的 √

# ③ 编译（F7）→ 产物 MDK-ARM/*.hex

# ④ 连接调试器，烧录：
#    Keil → Flash → Download（或 F8）
#    或用命令行 flm：<Keil>/ARM/FLM/CMSIS_DP/CMP 通过 ulink/jlink 烧 *.hex
```

**烧录后首次上电**：

```
① 先连调试器 + 供电，等继电器/电源稳定
② 遥控器滑键先置于 OFF（C 模式）再上电
③ 上电完成后再拨到运控模式 —— 见 §4 真机复现的起立/设零点顺序
```

> 引脚外设配置若要改：用 STM32CubeMX 打开 `.ioc` → 改配置 → `Generate Code`；
> `/* USER CODE BEGIN/END */` 内代码会被保留。

```

  Commnuicate_Drivers/ CAN/FDCAN · USART · USB
  Hardware_Drivers/   Motor_DJI/Unitree/DAMIAO · Remote_Control · Referee_Unpack · SuperCap · Laser
  Robot_Application/  ★ Chassis.c（底盘运控）· RoboControl.c（状态调度）· Communicate · Gimbal · INS · Shoot · Aim
```

## 4. 部署 / 真机复现

### 4.1 复现所需硬件

| 组件 | 数量 | 备注 |
|------|------|------|
| STM32G474VETx 主控板（含强弱电/驱动）| 1 | 烧录固件 |
| 串联腿机构 + 关节电机 DAMIAO 8009 | 4 | FDCAN1，MIT 力控 |
| 轮电机 DJI M3508 | 2 | FDCAN2，250Hz 力矩 |
| 机身姿态 BMI088 + 外部 IMU | 各 1 | SPI / FDCAN3 |
| 裁判系统 | 1 | UART4/5，功率上限 |
| 超级电容 | 1 | FDCAN1 |
| 遥控器 DR16 + 接收机 | 1 | USART1 SBUS |
| 手动/自动设零点机构 | — | 关节绝对磁编码，上电需设零 |

### 4.2 上电起立顺序（防疯车）

```
① 断电装好机器人 → 连遥控（滑键置 OFF/C 模式）
② 上电听主板 LED/蜂鸣 → 等待 INS 收敛
③ 触发「设零点」（遥控组合键）→ 系统延时 100ms 防设零后直接进运控疯车
④ 触发「缓起立」（Smooth_Restand）→ 缓慢收腿，Allow_to_Stand 就绪后进入常规运控
⑤ 才可拨摇杆下发 Vx/Vy/Wz 行驶
```

> ⚠ 倒地状态下不要直接下发运控速度——必须先缓起立 / 翻倒自起回正。

### 4.3 调试链路

- **VOFA 波形**：USB CDC 虚拟串口 + VOFA+（JustFloat）看电机速度/电流/姿态角。
- **CAN 观察**：FDCAN1/2/3 挂 CAN 分析仪核对帧速率与 ID（超电 0x030/0x031、轮电机、关节电机）。

## 5. 常见坑速查

| 现象 | 处置 |
|------|------|
| 编译报 `arm_math.h: No such file` | **未装 ARM.CMSIS-DSP 包**：Keil Pack Installer 安装后重编译 |
| 编译错崩在启动文件/汇编 | **编译器切到 AC5**：keil`.uvprojx` 用 AC6，恢复 `<uAC6>` / 保持默认 |
| 找不到 `STM32G4xxD.h` 等设备头 | 装 **Keil.STM32G4xx_DFP** |
| 烧录失败 / 连不上芯片 | 检查调试器驱动与 SWD 引脚、供电是否就位；便携机少用扩展坞供电 |
| 设完零点直接疯车 | 设零后需 `osDelay(100)` 再进运控；确认未越过 `Allow_to_Stand` 门控 |
| 上电/起立腿长突跳 | 必须先走**缓起立**（`Smooth_Restand_Func`），未就绪 `Allow_to_Stand_Flag=0` 不直发运控 |
| 高速控制发散 / 追不上目标 | `V_limit` 随腿长线性递减，检查是否在高腿长下触发限速 |
